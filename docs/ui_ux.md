# UI / UX Notes

- **Dark cyber-defence palette** keeps focus on critical alerts and works well in SOC/war-room lighting. Neon accents convey urgency without overwhelming.
- **Dashboard layout** pairs EU map (left) with campaign list (right) to allow instant geo-risk orientation.
- **Filter bar** exposes the most-used knobs (sector, country, min risk). Analysts can zero in on their remit fast.
- **Campaign detail** mixes qualitative (description, sector) and quantitative (risk score, timeline) cues. Entity histogram highlights dominant IOCs or actors.
- **Event detail** emphasises provenance, scoring, and extracted entities with quick links back to campaigns. Highlighting entities inline speeds skimming.
- **Responsive design** collapses map/list stacking on small screens for field analysts.
